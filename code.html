Where to paste it

  
Wix: Settings, Custom Code, Add Custom Code. Paste it, pick your pages and choose Head. Needs a Premium plan.

  
Squarespace: Code Injection, then the Header box. Needs a paid plan.

  
WordPress: install the free WPCode plugin, then Code Snippets, Header & Footer, Header.

  
Shopify: Online Store, Themes, Edit code, theme.liquid. Paste it just above </head>.

  
Webflow: Site settings, Custom code, Head code. Needs a paid site plan.

  
Made with AI: tell it "Add this script tag to the <head> of every page that should be locked, exactly as written", then paste the line.

  
Coded it yourself: paste it in the <head>. Your site needs to be on https for the camera to work.


  
Options

  
Add any of these inside the script tag, before the >:

  
data-title="Your heading" changes the heading.

     data-max-seconds="30" changes the time to finish (25 by default).

     data-remember="false" makes people skull every time, instead of staying unlocked until they close the browser.
