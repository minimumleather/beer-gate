3. Paste it into your website

      
Pick how your site was made. Put the code only on the pages you want locked, or on every page to lock the whole site.


      

        Wix
        

          
    
            
  1. In your Wix dashboard, go to Settings, then scroll to Advanced and open Custom Code.
    2. 
            
  2. Click + Add Custom Code and paste your code into the box.
    3. 
            
  3. Under Add Code to Pages, choose All pages or pick the pages to lock.
    4. 
            
  4. Under Place Code in, choose Head, then click Apply.
    5. 
          

          
Wix only allows custom code on Premium plans with a connected domain. Don't use the "Embed HTML" element: it runs in a small box that can't cover the page or use the camera.

        

      


      

        Squarespace
        

          
    
            
  1. Open the Code Injection panel. If you can't find it, search "Code Injection" in the Squarespace menu.
    2. 
            
  2. Paste your code into the Header box and click Save. This locks every page.
    3. 
            
  3. To lock just one page instead, open that page's Settings, go to Advanced, and paste the code into Page Header Code Injection.
    4. 
          

          
Code Injection is only on paid Squarespace plans that include custom code.

        

      


      

        WordPress
        

          
    
            
  1. Install the free WPCode plugin (Plugins, Add New, search "WPCode").
    2. 
            
  2. Go to Code Snippets, then Header & Footer.
    3. 
            
  3. Paste your code into the Header box and click Save Changes.
    4. 
          

          
On WordPress.com (not self-hosted), plugins need a Business plan or higher.

        

      


      

        Shopify
        

          
    
            
  1. Go to Online Store, then Themes. Next to your theme, click ⋯ then Edit code.
    2. 
            
  2. Open layout/theme.liquid.
    3. 
            
  3. Paste your code on the line just above </head>, then click Save.
    4. 
          

        

      


      

        Webflow
        

          
    
            
  1. Open Site settings, then Custom code.
    2. 
            
  2. Paste your code into Head code, save, and publish your site.
    3. 
            
  3. To lock one page instead, open that page's settings and paste it under Custom code, Inside <head> tag.
    4. 
          

          
Webflow needs a paid site plan for custom code.

        Coded it yourself
        

          
Paste the code inside the <head> of each page you want locked, then upload as usual. Your site needs to be on https://, or browsers won't allow the camera.

          
When someone passes, Beer Password fires an event you can listen for:

          
document.addEventListener("beerpassword:unlock", (e) => {
  console.log("Skulled in", e.detail.seconds, "seconds");
});

          
Run BeerPassword.reset() to lock it again, or add data-auto="false" to the tag and call BeerPassword.open() to open it on demand.
